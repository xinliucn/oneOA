# SuperApp Nuxt Module

Nuxt module and playground for the SuperApp experience.

## Local Development

```bash
npm install
npm run dev:prepare
npm run dev
```

## Common Commands

```bash
npm run dev:build
npm run lint
npm run test
npm run test:types
```

## Playground Configuration

Copy `playground/.env.example` to `playground/.env` and fill in environment-specific values. Keep real secrets out of committed files.
